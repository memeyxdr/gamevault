

# GameVault

GameVault is a static React app built with Vite. It runs entirely in the browser; user settings and edits are stored in localStorage.

## Run locally

Prerequisite: Node.js.

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Build static files with `npm run build`; Vite writes them to `dist/`.

GitHub Pages deployment is configured in `.github/workflows/deploy.yml`.
